# 弹壳风暴

一款纯前端 HTML 射击小游戏：单文件实现，打开即玩，无需服务器、无需联网资源。

## 玩法

- 操作角色在战场中移动，自动瞄准最近的敌人并开火
- 击倒敌人、收集奖励、强化角色，挑战更高分数

## 操作方式

| 设备 | 操作 |
| --- | --- |
| 手机 | 按住屏幕任意位置拖动，出现摇杆控制移动 |
| 电脑 | WASD / 方向键移动，Esc 暂停 |

## 技术说明

- 单文件 HTML + CSS + JavaScript，Canvas 渲染
- 无任何外部依赖：图片、样式、脚本全部内嵌
- 进度与最高分保存在浏览器本地存储（localStorage），不依赖后端
